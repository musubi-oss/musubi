## Top gaps for musubi

Ranked by how much a studio choosing between AGS and musubi would weigh them; each with a one-line implementation sketch.

1. **Client SDKs & engine plugins (Unreal SDK/OSS, Unity, Godot, Roblox, consoles)** — Ship a generated Rust→C/C++ core from `openapi.json` + `realtime.rs` (proto) with thin Unreal (OSS interface) and Unity (C#) wrappers; publish per-console transport shims.
2. **Admin console (AGS Admin Portal + Extend App UI)** — Minimal web console over existing `/v1/admin/*` routes: user lookup, bans, economy, leaderboards, fleet status, audit; allow modules to register custom admin pages.
3. **Real-money commerce: orders, PSP aggregators (Adyen/Stripe/Xsolla/PayPal), invoices, refunds, tax, hosted payment station** — Add an `orders` table + state machine in `musubi-economy`, Stripe Checkout + Adyen Drop-in webhooks, CSV invoice export, refund → revoke grants.
