# Competitor teardown: Steamworks backend features vs musubi

| | |
|---|---|
| **Product** | Steamworks (Valve) — backend/Web API feature set: user auth tickets, lobbies & matchmaking, leaderboards, stats & achievements, Inventory Service, microtransactions, Steam Cloud, Game Servers, Networking Sockets / Steam Datagram Relay, plus adjacent Workshop/UGC, anti-cheat, social and partner Web API surfaces |
| **Pricing / licensing** | No separate fee: all backend services are included once a title is published on Steam (USD 100 app fee, Valve's standard revenue share on store/MTX sales; Steam Wallet is the mandatory processor for in-game purchases). SDK is proprietary (Steamworks SDK Access Agreement); GameNetworkingSockets is BSD but without relay access. No tiers — gates are *permissions* (publisher Web API key categories, "Manage Signing", Profile Features Limited until vetted) and *platform rules* (SDR for non-Steam platforms needs Valve approval), not price tiers |
| **Hosting model** | Fully Valve-hosted SaaS (lobbies, leaderboards, stats, inventory, cloud, MTX, relay PoPs). No self-hosting. Studios host their own game servers and any game coordinator / "secure purchasing server" |
| **SDKs / platforms** | Native C++ SDK + flat C API: Windows x86/x64, macOS, Linux x64, linuxarm64 and androidarm64 (since 1.63); community wrappers (Steamworks.NET, Facepunch.Steamworks, Godot, Unreal OnlineSubsystemSteam). Web API: REST (JSON/XML/VDF) with publisher keys or user OAuth 2.0 tokens; consoles/mobile can call Web API + SDR via Valve approval |
| **Release cadence** | SDK: ~2 releases per year — 1.61 (2024-11-08), 1.62 (2025-03-14), 1.63 (2025-11-19), 1.64 (2026-03-11), 1.65 (2026-07-24, re-released 07-27 and 07-31). Backend/Web API features ship continuously without version numbers (announced on the Steamworks Development group) |
| **Last release** | SDK 1.65, 2026-07-24 (re-release 2026-07-31); most recent backend change in the scan window: Updated Achievement System (achievement sets, 5,000 limit) announced 2026-10 |
| **musubi baseline** | musubi-oss/musubi @ main (cloned 2026-10-18): Rust, Apache-2.0, single binary, 578 HTTP routes in `openapi.rs` ROUTES + realtime socket; status alpha, no client SDKs, no admin console (README) |

Status legend: `have` = present with README/route/crate evidence; `partial` = comparable but weaker (weakness stated); `missing` = nothing comparable after `rg`; `n/a` = platform-only / not meaningful for a self-hosted backend. Source URLs are relative to https://partner.steamgames.com/doc/ unless absolute.
