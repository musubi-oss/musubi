# Competitor teardown: Colyseus (OSS + Colyseus Cloud + Arena) vs musubi

Date: 2026-10-18. Scope: docs.colyseus.io (142 sitemap pages, read from the docs repo `colyseus/docs`), github.com/colyseus/colyseus (monorepo at `0029df2`, 2026-10-16), package CHANGELOGs, GitHub Releases feed, npm release timeline. musubi reference: `musubi-oss/musubi` main (README, `docs/parity.md`, `openapi.rs` ROUTES, `realtime.rs`, 122 migrations, `musubi-cli`, `deploy/`).

## Header

| field | Colyseus |
|---|---|
| Product | Colyseus multiplayer framework: `colyseus` bundle (`@colyseus/core`, `/schema`, `/sdk`, `/auth`, `/database`, `/admin`, `/monitor`, `/playground`, `/loadtest`, `/testing`, `/tools`, `/traefik`, `/yjs`, `/react`, transports, drivers, presence, room-plugins) + **Colyseus Cloud** (managed hosting by the same team). **Arena** is the legacy name: `@colyseus/arena` was renamed `@colyseus/tools` in 0.15 and `arena.config.ts`/`arena.env` only survive in old tutorials; there is no separate Arena product page in the current docs, Colyseus Cloud is its successor. |
| Pricing / licensing | OSS: MIT, free for commercial use. Cloud: monthly subscription per provisioned instance, charged upfront with proration credits; compute tiers Low Performance / High Frequency (recommended) / High Performance / Dedicated (Enterprise, AMD EPYC); paid add-on DDoS protection (L3/L4, 10 Gbps per instance); pricing simulator at colyseus.io/pricing (no public per-plan numbers in docs). Several packages are beta (`@colyseus/auth`, `/admin`, `/database` 0.18, Cloud API) or experimental (WebTransport, Traefik, netcode input/prediction). |
| Hosting model | Self-host any Node.js ≥ 22 host (PM2 + NGINX/Traefik, Redis presence+driver for multi-process, Vultr Marketplace image, Vite plugin, `Server.serverless()` for export-default hosts) or Colyseus Cloud (NGINX+PM2 VMs, vertical or horizontal scale strategy per location, regions EU/NA/AS/AF/AU/SA across 20 countries, GitHub auto-deploy, encrypted env vars, read-only Cloud API, 35-day metrics retention, maintenance mode). |
| SDKs / platforms | JavaScript/TypeScript (+ React hooks), Unity (C#), MonoGame, Godot (Native SDK bindings), GameMaker, Flutter/Dart, Swift (iOS/macOS/tvOS), Defold (Lua), Haxe, Cocos Creator 3, Construct 3, Native C core, Discord Activity template, WeChat mini-games. Schema codegen for C#, C++, Haxe, Dart. Netcode (`room.input`, `Predict`) in all official SDKs since 0.18 (Godot/GameMaker gaps noted on roadmap). |
| Release cadence | Minor lines: 0.15 May 2023 (13 patches), 0.16 Feb 2025 (6), 0.17 Jan 2026 (10), 0.18 May 2026 (10 bundle patches so far). 22 stable `colyseus` bundle releases on npm between 2025-04 and 2026-09; the GitHub Releases feed shows 90 per-package releases between 2026-04-11 and 2026-10-16 (`@colyseus/core` alone 0.18.0 → 0.18.19 in five months, roughly weekly). Breaking-change migration guides per minor. |
| Last release | `@colyseus/core` 0.18.19 on 2026-10-16 (GitHub release); `colyseus` bundle 0.18.9 on 2026-09-30 (npm `latest`), `next` tag 0.18.3. |

Status legend: `have` = musubi has it (route/crate/README cited); `partial` = exists but weaker (weakness stated); `missing` = nothing comparable after `rg` on the repo; `n/a` = not meaningful for a self-hosted OSS backend.

Totals: **145 features** — have 66, partial 48, missing 16, n/a 15.

## Top gaps for musubi

Ranked by how much a studio choosing between the two would care.

1. **Client SDKs (`missing`)** — Colyseus ships 14 platform SDKs with join/reconnect/backoff/state callbacks; musubi has none. Sketch: generate a TS core from `openapi.json` + `realtime.rs` (serde → TS types via IDL), ship `@musubi/sdk` (WS/WebTransport, session resume, exponential backoff defaults 100 ms→5 s/15 tries, message queue while offline), then C# (Unity/Unreal via C ABI) and GDScript bindings from the same C core.
2. **Client prediction / reconciliation / interpolation library (`missing`)** — `Predict` (reconciler, sim, lerp/extrapolate/damped/reckon, optimistic events, predicted spawns). Sketch: expose the existing rollback inputs + `match_input_ack` in the SDK, add a shared `step(ctx,state,cmd)` contract for WASM match modules compiled to both wasm32 (server) and the client, with snapshot interpolation buffer and `snap` thresholds.
3. **Admin console UI (`missing`)** — `@colyseus/admin`: user management, bans, sessions, table CRUD, room inspector, widgets, RBAC, audit. Sketch: a static SPA served by `musubi-server` under `/admin` backed by existing `/v1/admin/*` routes and operator keys/SSO, resource browser over storage collections, live match/world inspector from `GET /v1/admin/cluster/*`.
4. **Monitor + Playground dev UIs (`missing`/`partial`)** — browser room list, state tree, send-message-as-client, HTTP endpoint tester, simulated drops. Sketch: dev-only pages in `musubi dev` (Swagger UI from `/openapi.json`, WS console using `realtime.rs` enums, match state viewer from snapshots).
5. **Field-level binary state codec with client callbacks (`partial`)** — `@colyseus/schema` 5: 63 fields, change tracking per property, `onAdd/onRemove/listen`, `StateView`, streaming collections (`maxPerTick` 32), `.unreliable()/.patchOnly()/.fullStateOnly()/.stream()`, quantized floats/angles. Sketch: extend IDL with per-field attributes (`#[unreliable]`, `#[quantized(min,max,bits)]`, `#[view]`), compile to a postcard field-mask delta instead of RFC 6902 for hot paths, generate client decoders with change callbacks.
6. **Engine tutorials, templates and examples (`missing`)** — `npm create colyseus-app`, 12 tutorials, 8 example projects, webgame template, Prediction Playground. Sketch: `musubi init` template (module + TS client), Phaser/Unity/Godot starter repos, docs site.
7. **Generic OAuth2 provider catalog (`partial`)** — 200+ providers via `grant` (Discord, Twitch, X). Sketch: table-driven OAuth2 authorization-code flow in `musubi-auth` (`[auth.oauth.<id>] authorize_url, token_url, userinfo_url, scopes`) reusing the OIDC linking tables.
8. **Test kit for module authors (`partial`)** — `@colyseus/testing` (`waitForNextPatch`, `waitForMessage`, SDK + HTTP client). Sketch: `musubi-testkit` crate: in-process server with embedded Postgres (pgtemp/testcontainers), typed client, match-tick stepping helpers; publish on crates.io.
9. **Local dev without Postgres (`partial`)** — Colyseus boots on SQLite/PGlite by default. Sketch: `musubi dev --embedded` that downloads/starts an embedded Postgres (pg-embed) or ships a single-node Docker compose; keeps SQL dialect single.
10. **Simulated latency / network conditions (`missing`)** — `COLYSEUS_LATENCY`, `simulateLatency()`, SDK jitter sliders. Sketch: `[dev] latency_ms, jitter_ms, loss_pct` applied in `realtime/hub.rs` send path when `MUSUBI_ENV=dev`.
11. **Arbitrary HTTP routes + middleware (`partial`)** — `createEndpoint/createRouter`, Express, CORS, basicAuth, typed `client.http`. Sketch: allow WASM modules to export `http_<name>` handlers mounted under `/v1/x/{module}/{name}` with method/verb map and middleware ordering declared in module manifest, surfaced in OpenAPI.
12. **GeoIP plugin (`partial`)** — MMDB lookup with MaxMind/DB-IP auto-download, `client.geoip`. Sketch: optional `maxminddb` crate in `musubi-edge`, populate `session.country/region/asn` when CDN headers are absent, expose to modules and matchmaker ping windows.
13. **CRDT document sync (`missing`)** — `@colyseus/yjs` room plugin + client provider. Sketch: a `yrs`-backed channel kind (`ChannelKind::Doc`) with update broadcast and storage-backed snapshots.
14. **Per-resource moderator roles + admin notes (`partial`)** — `db.moderation.assignMod(user, collection)`, `db.notes`, segments widget. Sketch: scope operator keys/SSO roles to collections (`permissions` table keyed by role+collection+action) and add `account_notes` table surfaced in admin routes.
15. **Traefik/service-discovery module and marketplace images (`partial`)** — Sketch: publish a Hetzner/Vultr/DigitalOcean marketplace image from the Terraform modules and emit Traefik/Consul-compatible registration from cluster membership events.
