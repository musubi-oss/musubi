| | |
|---|---|
| **Product** | LootLocker — hosted game backend / LiveOps platform (https://lootlocker.com, docs https://docs.lootlocker.com, API reference https://ref.lootlocker.com) |
| **Pricing / licensing** | Proprietary SaaS. Personal: free, < $100k combined revenue + funding, 10,000 MAU cap (new players blocked above cap until next month), no console platforms, Discord support. Pro: $500/month incl. 10,000 MAU, $0.015 per additional MAU, console platforms, dedicated success manager, 30-day card-required trial. Publisher: custom/volume pricing, publisher console, loyalty and cross-game rewards, custom terms and SLAs. Enterprise License: source-code access and self-hosted deployment on request. Rich Presence limited to paying customers. |
| **Hosting model** | Multi-tenant SaaS (api.lootlocker.com, console.lootlocker.com, hosted auth.game and playtest.game pages, CDN for player/asset files). No public region choice, no published uptime SLA, no documented rate limits. Self-hosting only via Enterprise License. |
| **SDKs / platforms** | Unity (2019.1+, OpenUPM/git/.unitypackage, v8.2.0), Unreal (4.27+, Fab/GitHub, C++ + Blueprints, v10.6.0), Unreal Server SDK (v6.7.1), Godot 4.3+ (feature subset), GameMaker (leaderboards only), Construct 3, GDevelop, REST (Game, Server, Admin, Auth Client APIs). Auth providers: guest, White Label email/password + magic link, Steam, Epic, Apple, Game Center, Google, Google Play Games, Nintendo Switch, Xbox, Meta/Oculus, Discord, PSN, Twitch (linking). IAP: Apple, Google Play, Steam, Epic Games Store, Microsoft Store, PlayStation Store, Stripe. |

| **Last release** | October 12, 2026 (Updated Reward Modal); last SDKs: Unreal SDK v10.6.0 and Unreal Server SDK v6.7.1 (Oct 1, 2026), Unity SDK v8.2.0 (Sep 30, 2026). |
