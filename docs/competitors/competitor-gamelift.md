# Competitor scan: Amazon GameLift vs musubi

**Scan date:** 2026-10-18. **Scope:** Amazon GameLift Servers (managed EC2 fleets, managed container fleets, Anywhere, FleetIQ, queues, Realtime Servers), Amazon GameLift FlexMatch, Amazon GameLift Streams. **musubi revision:** `musubi-oss/musubi` main as cloned 2026-10-18 (538 HTTP routes in `crates/musubi-server/src/openapi.rs`, 122 migrations, 22 crates).

| | |
|---|---|
| Product | Amazon GameLift (branded "Amazon GameLift Servers" for hosting + FlexMatch; "Amazon GameLift Streams" for pixel streaming) |
| Pricing / licensing | Proprietary AWS service, pay-as-you-go. Managed EC2 / container fleets: EC2 instance-hours (On-Demand or Spot, Linux or Windows) + data transfer out; bandwidth free on generation-6+ instance types since 2025-10. Anywhere: per game session placed + per server-process connection-minute (customer supplies hardware). FlexMatch: per matchmaking request (standalone billed separately; bundled when used with GameLift hosting). Streams: per stream-hour by stream class (gen4n/gen5n/gen6n/gen6e, small..pro) + always-on capacity billed while allocated. 12-month AWS Free Tier for new accounts. No seat/enterprise tiers; Enterprise Support is a separate AWS contract. Server/client SDKs, plugins, Agent, wrapper and toolkit are Apache-2.0 on GitHub (org `amazon-gamelift`). |
| Hosting model | Fully managed on AWS (EC2 fleets, container fleets on ECR images), customer hardware via Anywhere (RegisterCompute + GameLift Agent), customer EC2 Auto Scaling groups via FleetIQ; multi-location fleets across ~30 Regions + Local Zones; China Regions on separate accounts. No self-hosted control plane. |
| SDKs / platforms | Server SDK 5.x: C++ 5.6.0, C# 5.5.1 (.NET 6/8), Go 5.6.0, Unreal 5.6.0 (UE 5.8), Unity 5.5.1; plugins Unreal 3.4.0 and Unity 3.3.1; client SDKs (player gateway + UDP beacons) C++ 1.0.1, Unreal 1.0.1, C# 1.0.0, Unity 1.0.0; Realtime client SDK 1.2.0 (C#); service API via all AWS SDKs (JSON + Smithy RPC v2 CBOR from 2026-04). Server OS: Amazon Linux 2 / 2023, Windows Server 2016 / 2022 (containers Linux only). Streams Web SDK (JS) for Chrome/Edge/Safari/Firefox on Windows/macOS/Linux/iOS/Android/TV. |
| Release cadence | Service release notes list 22 dated releases between 2024-02-13 and 2026-08-04: roughly monthly in 2025–2026 (16 releases in 20 months), each bundling SDK/plugin bumps. Streams: continuous (shader caching, stream URLs, custom aspect ratio, dynamic resolution, gen6 classes, performance overlay) without a dated table. |
| Last release | 2026-08-04 (container-group CPU bursting; Server SDK C++/Go/Unreal 5.6.0; Unreal plugin 3.4.0) |

## Top gaps for musubi

Ranked by how much a studio choosing between the two would care.

1. **Declarative matchmaking rule sets (FlexMatch rule language)** — `missing/partial`. Sketch: add `rules: Vec<Rule>` to `QueueConfig` (comparison / distance / batchDistance / collection / compound / latency / sort) evaluated in `queue::quality`, plus `expansions[]` targeting any rule/team field with absolute `wait_secs`; validate via a `POST /v1/server/matchmaker/queues/validate`.
2. **Typed player attributes + asymmetric named teams** — `partial`. Sketch: `playerAttributes{name,type,default}` schema on the queue; `Teams` → `Vec<TeamDef{name,min,max,quantity}>` with FlexMatch-style fill order; return team names in `matchmaker_matched`.
3. **Managed relay / IP-hiding player gateway + DDoS posture** — `missing`. Sketch: make `musubi-edge` a UDP/QUIC relay that terminates per-player connect tokens and forwards to fleet servers; publish `relay_endpoint` instead of server IP in `Allocation`; per-token rate limits and Prometheus drop counters.
4. **Native server SDK libraries (C++/C#/Go/Unreal/Unity)** — `partial`. Sketch: generate thin SDKs from `musubi idl` for `/v1/gameserver/*` with `InitSDK/ProcessReady/Health/OnAllocate/Shutdown` callbacks and long-poll `watch`; ship Unreal + Unity plugins.
5. **Client SDKs (C++/C#/Unity/Unreal)** — `missing`. Sketch: codegen from `musubi-proto/src/realtime.rs` + REST OpenAPI; include region probing (`GET /v1/regions` + UDP echo) and matchmaking helpers.
6. **Game-server log capture (`GetGameSessionLogUrl`)** — `missing`. Sketch: `log_paths` on `FleetSpec`; providers upload to S3-compatible storage (`musubi-storage`) on shutdown; `GET /v1/server/gameservers/{id}/logs` signed URL with retention.
7. **Game-server telemetry ingestion (OpenTelemetry server metrics)** — `partial`. Sketch: `POST /v1/gameserver/metrics` (OTLP/JSON) tagged by fleet/build/region; expose tick/packet/CCU gauges on `/metrics`; ship Grafana dashboards in `deploy/`.
8. **Async placement object + placement events** — `partial`. Sketch: `POST /v1/server/placements` returns `placement_id` with status PENDING/FULFILLED/TIMED_OUT/CANCELLED, `DELETE` to stop, timeout and latency policies, webhook `placement.*` events.
9. **Metric/threshold rule-based autoscaling + suspend** — `missing`. Sketch: `ScalePolicy.rules[{metric, op, threshold, periods, adjustment}]` evaluated by the reconciler on `musubi-fleet` gauges; `paused: bool` flag on fleet to freeze scaling.
10. **Spot / preemptible capacity & termination notice** — `missing`. Sketch: provider capability `preemptible` with `termination_at` surfaced to servers via `GET /v1/gameserver` + `watch` event; reconciler drains and re-places.
11. **Estimated wait time to clients + per-rule evaluation metrics** — `missing`. Sketch: compute ETA from the `waits` ring buffer per (queue, region) and send in `matchmaker_add` ack; export `rejections` as Prometheus counters per rule.
12. **Per-player session creation limit policy and game-session protection** — `missing/partial`. Sketch: `creation_limit{per_creator, period_min}` on pool; `protected: bool` on allocation that the reaper respects.
13. **Admin console UI** — `missing`. Sketch: SPA over existing admin routes (fleets, builds, queues, matchmaker stats, sessions lookup) — the backend-first rule means this stays last.
14. **Container-group semantics (sidecars, per-instance groups, health/depends-on, min-healthy rolling deploy)** — `partial`. Sketch: extend `FleetSpec` with `containers[]` and render to k8s Pod spec / docker compose; `DeploymentConfig{min_healthy_pct, impairment: rollback}` on build promote.
15. **Declarative IaC provider (Terraform/CRD) for fleets, pools and queues** — `partial`. Sketch: Kubernetes CRDs (`MusubiFleet`, `MusubiQueue`) reconciled into the API, or a Terraform provider generated from OpenAPI.
