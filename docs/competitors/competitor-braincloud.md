| | |
|---|---|
| **Product** | brainCloud — Backend-as-a-Service for games/apps by bitHeads Inc. (Ottawa). Java/Spring/Karaf/Vert.x API servers, MongoDB (Atlas; DocumentDB experimental), Redis, hosted on AWS (US East Ohio primary). Cloud Code = server-side JavaScript on Mozilla Rhino (ES6). |
| **Pricing / licensing** | Closed source, per-app usage-based SaaS (“Public BaaS”). Basic: Development **Free** (100 DAU, 1,000 accounts max, 1M API calls, 100 MB files, no live IAP), Lite $15/mo, Standard $30, Business $99. **Plus** plans unlock RTT (realtime), Deep Data (Custom Entities, Messaging, Chat history) and brainCloud-hosted Room/Relay servers: Dev+ $5 (200 DAU/2,000 accounts/20 RTT conns), Lite+ $25, Standard+ $50, Business+ $199 (15M calls, 250 RTT conns). **Bulk+** prepaid: 100M calls $955 → 1B calls $7,705/mo. Overage: API calls $8.50–$12/million, files $0.05/GB storage + $0.15/GB transfer, Deep Data $0.45/GB/day (×5 indexes, ×10 Redis), RTT = 1 count per 100 messages + 10 counts/connection-hour over quota, hosted servers = AWS cost +25% +$0.03/h, dormant accounts (>365 d) $75/million/mo unless auto-deleted. **Enterprise features** (LiveOps Campaigns, 60-day retention) = Business/Business+ and up. brainBot AI = all paid plans, 35% markup on tokens. Support plans: free / $150 / $500 / $1,000+ per month. **Private Licenses**: fully-managed instance in customer's own cloud (AWS, Azure, GCP), SSO, separate agreement. Source: https://www.getbraincloud.com/pricing/ |

## Top gaps for musubi

1. **Client SDKs (Unity/C#, Unreal, C++, JS/TS, Godot, Dart, Java)** — brainCloud ships 12 client libs + 6 S2S libs with auto-reconnect, bundling, compression, stored ids. Sketch: generate typed clients from `GET /openapi.json` + `musubi-idl` for realtime; ship C# (Unity/Godot), TS and finish the Unreal plugin first.
2. **Admin console / CSR tooling** — Portal-X has ~110 screens incl. User Browser, entity editors, personalized pricing, API Explorer. Sketch: web console over existing `/v1/admin/*` routes with support/liveops/ops role keys; start with user lookup, ledger/inventory adjust, bans, storage editor.
3. **A/B testing & LiveOps campaigns** — segment-targeted scenarios, traffic allocation, overrides, significance analytics (Enterprise). Sketch: `experiments` table + deterministic bucketing by account id, overrides merged into `/v1/configs` and store prices, outcome events to Zanshin.
4. **Segments with a rule builder** — attribute/spend/platform/date predicates, nested AND/OR, daily refresh, usable by push/promos/scripts. Sketch: extend `[audiences]` to persisted segment definitions with CEL predicates evaluated nightly into a membership table + `GET /v1/account/segments`.
5. **Redemption-code campaigns** — single-use generated codes (25-char), shared multi-use codes, reward payloads, async processing, redemption history. Sketch: `redemption_campaigns` + `redemption_codes` tables, `POST /v1/redeem {code}` granting a reward table, `GET /v1/server/redemption/{campaign}/generate`.
6. **Turn-based async match service** — create/submit turn/complete/abandon with versioned state, summaries, push-on-turn, history. Sketch: `async_matches` collection with CAS versions + notification hook; `/v1/async_matches/*` routes.
7. **Built-in analytics (DAU, retention D1–D30, revenue, platform/region, session duration)** — brainCloud shows these in-portal. Sketch: daily rollup job from the event bus into `metrics_daily` + `GET /v1/admin/metrics`, or document the Zanshin path as first-class.
8. **Files service (user files, global files, group files with CDN URLs)** — 20 MB user files, 50 MB global files, folders, ACL. Sketch: generalize `blobstore.rs` behind `/v1/files` with presigned S3/MinIO uploads, owner/group/global scopes, CDN URL field.
9. **Global/app statistics + rich stat grammar** — app-wide counters and `INC_TO_LIMIT`/`MAX`/`MIN` ops. Sketch: `global_stats` table with atomic operators; extend `/v1/stats` grammar.
10. **Item lifecycle & effects** — publish/retire/revoke states, cooldown/regeneration on use, timed status effects applied to the player. Sketch: `status` field on item defs, `account_statuses` table with expiry, `use` endpoint applying cooldown/regen.
11. **Tournament templates with recurring periods, entry fees and divisions** — brainCloud attaches templates to rotating leaderboards and auto-instances divisions of N players. Sketch: tournament `schedule` (cron) + `entry_fee` + `division_size` → auto-create instances per rotation using existing buckets/prizes.
12. **Store/IAP coverage: Amazon Appstore, Facebook, Microsoft Store, Meta Horizon** + Steam app-ownership check at login. Sketch: add providers to `musubi-integrations/iap.rs` (RVS, Graph API, Microsoft Collections, Horizon verify), `[auth.steam] verify_ownership`.
13. **Minimum client version gate + per-operation API blocking** — force upgrades and block client-callable routes. Sketch: `[clients] min_version` checked on `X-Musubi-Client`, admin `PUT /v1/admin/api_blocks`.
14. **Dormant-account archive/auto-delete policy** — configurable inactivity window with email notice. Sketch: retention lease job + `[retention] dormant_days` + `account.dormant` event.
15. **Scripting ergonomics: JS/Lua scripting, in-browser editor, VS Code/MCP tooling** — WASM-only raises the floor for designers. Sketch: optional QuickJS/Lua module host behind the same `rpc`/hooks API; MCP server wrapping the admin API.
